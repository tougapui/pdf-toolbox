# 檔案工具箱 v3.0

繁體中文、免登入，支援 **PDF + 圖片** 的瀏覽器本機處理網站。

網站：https://pdf-toolbox-gold.vercel.app/

## PDF 工具（首頁）

| 工具 | 功能 |
|---|---|
| 合併 PDF | 上傳多份檔案、頁面預覽、勾選、拖曳重排 |
| 拆分／擷取頁面 | 勾選頁面、全選／取消、輸出 PDF／JPG／PNG、逐頁 PDF ZIP |
| 整理 PDF | 拖曳重排、刪除、複製與旋轉 |
| 旋轉 PDF | 指定頁面及 90／180／270 度 |
| 新增頁碼 | 選擇頁面、位置、起始頁碼 |
| PDF 轉圖片 | JPG／PNG、解析度選擇、單張或 ZIP |
| 圖片轉 PDF | JPG／PNG／WebP、預覽、拖曳排序、A4／原始比例 |
| 擷取 PDF 文字 | 擷取既有文字圖層，匯出 UTF-8 TXT |
| 加浮水印 | 文字浮水印、方向、透明度 |
| **壓縮 PDF** | **保留文字及向量內容的基本最佳化**，或 **掃描圖片型 PDF 的有損壓縮**；顯示壓縮前後大小 |

PDF 壓縮的兩種模式：

- **保留文字與版面**：使用 PDF-Lib 的物件串流重新打包，若整份 PDF 的輸出未比原始檔小，就不下載更大的副本。對已壓縮的影像資料可能完全無效，數位簽章或特殊互動功能可能失效。
- **掃描文件／圖片型**：利用 PDF.js 將選取頁面渲染成 JPEG，再用 PDF-Lib 組成新 PDF，畫質設定三段。適合掃描照片型 PDF，但**會失去可選取文字、書籤、超連結**，檔案也未必一定縮小。一次最多 50 頁。

## 圖片工具

網址：https://pdf-toolbox-gold.vercel.app/image-tools.html

| 工具 | 功能 |
|---|---|
| 局部修補／去除浮水印 | 在圖片上用筆刷／框選要修補的範圍，用附近像素填補，支援復原及原圖比較 |
| 壓縮圖片 | JPG／WebP 品質設定、最長邊尺寸、輸出與原檔大小比較 |
| 轉換圖片格式 | JPG、PNG、WebP 互轉 |
| 調整圖片尺寸 | 寬高輸入、鎖定比例 |
| 裁切圖片 | 直接在圖上畫框、套用裁切 |
  
局部修補**不需要 AI 或外部付費 API**。採用 JavaScript 邊界向內的相鄰像素修補，只適合小污點、較簡單背景或你有權修改的圖片。不會恢復被遮蔽的真實內容。複雜背景、人物、大片文字的品質不如生成式 AI。請勿用於未經授權的圖片。

圖片處理上限：單檔 80 MB；為避免瀏覽器記憶體不足，圖片會依需要限制於最長邊 4096 px、最多 1400 萬像素，可能縮小原始尺寸。局部修補一次最多 35 萬個像素。

## 隱私與相依套件

本工具透過瀏覽器 File API 讀取使用者選擇的檔案，圖片處理使用 Canvas。程式不會呼叫檔案上傳 API，也沒有文件儲存資料庫。

PDF 的 JavaScript 套件目前透過第三方 CDN 載入：
- PDF-Lib 1.17.1
- PDF.js 3.11.174
- JSZip 3.10.1

對高度機密資料，應使用自行託管依賴程式、離線且經安全審核的版本。**純前端不代表絕對零資安風險**。

不支援 OCR、PDF 轉可編輯 Word、解密 PDF、數位簽章製作。大型 PDF 可能耗盡裝置記憶體。

## 本機執行

~~~bash
python3 -m http.server 8000
~~~

開啟 http://localhost:8000/ 或 http://localhost:8000/image-tools.html 。

## 部署方式

Vercel 專案以直接上傳靜態檔案的方式部署。目前 GitHub 與 Vercel 尚未建立自動部署的 Git 整合；修改 GitHub 後，需要另外將最新檔案部署到 Vercel。
