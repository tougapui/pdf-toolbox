# PDF 工具箱 v2

繁體中文、免登入、瀏覽器本機處理的 PDF 工具。採用頁面縮圖預覽、勾選、全選／全取消與直接輸出格式選擇。

## 網站

https://pdf-toolbox-gold.vercel.app/

## 功能

| 工具 | 目前支援 |
| --- | --- |
| 合併 PDF | 多檔合併、頁面縮圖、頁面勾選、拖曳重排 |
| 拆分／擷取頁面 | 勾選頁面、全選／取消、輸出 PDF／JPG／PNG、逐頁 PDF ZIP |
| 整理 PDF | 頁面拖曳重排、複製、刪除、旋轉 90 度 |
| 旋轉 PDF | 勾選特定頁面，順時針旋轉 90／180／270 度 |
| 新增頁碼 | 選擇頁面、位置、起始頁碼 |
| PDF 轉圖片 | JPG／PNG、頁面勾選、三種解析度、單張下載或多張 ZIP |
| 圖片轉 PDF | JPG／PNG／WebP、預覽、重排、A4／原始比例 |
| 擷取 PDF 文字 | 勾選頁面、匯出 UTF-8 TXT |
| 加浮水印 | 可輸入中文字、調整方向與透明度、勾選頁面 |
| 縮小 PDF（影像型） | 重新輸出較小的影像型 PDF，三種畫質。會**失去文字選取、書籤及超連結**，且不保證檔案變小 |

### 已知限制

- 本工具不支援 OCR 掃描圖片文字辨識、PDF 轉可編輯 Word／PowerPoint／Excel、PDF 加密解密、電子簽章。
- 圖片轉換一次上限 150 頁；影像型 PDF 壓縮一次上限 50 頁。瀏覽器處理較大 PDF 時可能耗用較多記憶體。
- 某些受加密保護、損壞或含特殊編碼的 PDF 可能無法處理。
- 本工具的程式碼已實作上述功能，但不同瀏覽器及各類 PDF 檔案仍應個別測試。這不是針對所有文件格式的完整相容性保證。

## 隱私說明

原始文件由網頁的 File API 在使用者的瀏覽器內讀取；PDF-Lib、PDF.js、JSZip 均於瀏覽器內處理。程式碼不包含上傳原始文件的 API，也沒有使用後端資料庫儲存文件。

**提醒**：本版使用第三方 CDN 載入 JavaScript 套件，需要網路連線。這不等於可以保證完全零資安風險。對高度機密的檔案，建議使用自行託管依賴套件、斷網可用且經過安全審核的版本。

使用的套件：
- pdf-lib 1.17.1
- PDF.js 3.11.174
- JSZip 3.10.1

## 部署及更新

目前使用 Vercel 直接部署。由於 Vercel 帳號尚未完成 GitHub Integration 的授權，GitHub main 分支的更新**不會自動重新部署**到現有網址，需要手動更新 Vercel 部署，或完成 Vercel → GitHub 連結。

本機開發可在資料夾執行：

~~~bash
python3 -m http.server 8000
~~~

開啟 http://localhost:8000/ 。
